# Online Purchase Prediction using Machine Learning

## Course
SWE485 – Selected Topics in Software Engineering  
King Saud University | Second Semester 1447

## Overview
A machine learning system that predicts whether an online shopping session will result in a purchase using the **Online Shoppers Intention Dataset**.

## Objective
Analyze online shopping behavior and predict purchase completion using supervised machine learning classification.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Key Outcome
The model predicts whether a customer is likely to complete a purchase based on their online shopping session behavior.

## Project Type
**Academic Project**
