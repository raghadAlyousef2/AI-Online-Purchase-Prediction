# AI & Machine Learning Projects

A collection of academic projects focused on artificial intelligence,
machine learning, and data-driven solutions.

## Projects

### 1. Numou – Graduation Project

Numou is an AI-enabled Android educational application designed for
Arabic-speaking children aged 3–7. The application uses speech
recognition to support pronunciation assessment and OCR-based
techniques to recognize handwriting and tracing activities.

### 2. Online Purchase Prediction System – Selected Topics in Software Engineering (AI) Course

An academic machine learning project that predicts whether an online
shopper will complete a purchase using the Online Shoppers Intention
Dataset. The project applies supervised machine learning classification
to analyze browsing-session data and predict purchase intention.
